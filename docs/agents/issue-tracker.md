# Issue Tracker

- **Kind**: GitHub Issues
- **Tool**: `gh` CLI
- **External PRs as request surface**: false

## Conventions

- Issues are created and queried via the GitHub CLI (`gh issue create`, `gh issue list`, `gh issue view`).
- Issue descriptions should contain actionable requirements, acceptance criteria, and relevant technical context.
- Branches and pull requests reference issues by `#<issue-number>`.
