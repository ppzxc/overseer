## Consumer Rules

- Read `CONTEXT.md` at the repo root to understand domain vocabulary, system boundaries, and core concepts before planning architectural modifications.
- Consult `docs/adr/` when making or reviewing architectural decisions.
- Create new ADRs under `docs/adr/NNNN-title.md` when introducing significant design decisions or breaking architectural changes.
