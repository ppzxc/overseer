접근제어 솔루션 PoC 보고서: Teleport · Warpgate · JumpServer

2026-11-17 · 로컬 Docker PoC(운영 영향 없음) · 대상: CentOS 6/7, Rocky 8/9/10, PostgreSQL 16, MySQL 8.4, MariaDB 5.5/10.11/13
잠정 결론 CentOS 6·MariaDB 5.5까지 통제해야 하고 Google 로그인(GWS)과 PC 설치 불필요가 요구라면 Warpgate만 모두 충족한다. 단 1.0 이전 버전이다. 기본은 공용 계정 중계이고, 사람×서버마다 대상을 만들면 개인 OS 계정 1:1 매핑도 가능하다(시험 OK).
Teleport는 현대 OS만 대상일 때 개인 식별과 기능이 강하지만 CentOS 6·MariaDB 5.x는 통제 불가, GWS SSO는 Enterprise. JumpServer CE는 DB 네이티브 접속이 안 된다.

시험으로 확인한 것

  • Warpgate: CentOS 6·MariaDB 5.5 접속, 접근 승인, IP 차단·계정 잠금, TOTP, OpenBao 비밀 참조, 개인 OS 계정 1:1 매핑
  • Teleport: SSH/DB 접근, OS 계정 자동 생성, SCP 차단 / CentOS 6·MariaDB 5.5 불가
  • JumpServer: SSH 전 OS, 명령 필터, 계정 푸시 / DB는 구버전 magnus만

위험·한계

  • Warpgate 개인 매핑은 사람×서버만큼 대상이 늘어남(6명×서버 N대). 자동 생성 필요
  • Warpgate 녹화 기본 7일(설정 변경 필요), 키 입력 마스킹 없음, 로그 위변조 방지 기능 미확인
  • JumpServer 공식 compose는 docker.sock 마운트·privileged. Teleport 계정 삭제는 동기화 안 됨
